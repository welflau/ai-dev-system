# AI 生图导入 UE 项目设计文档

**版本**：v0.1  
**日期**：2026-07-07  
**状态**：设计阶段

---

## 1. 背景与目标

### 1.1 现状

AI 生图链路（LightAI → `image_processor.py` → `G_ArtRes/2d/generated/`）已完整闭环，图片落地后：
- 写入 `image_requests` 表（`result_path` 绝对路径）
- 写入 `art_assets` 表（`file_path` 相对路径）
- 推 SSE `image_generated` 事件

但链路止步于文件系统，**没有任何代码将图片导入 UE 项目的 Content 目录**。需要人工打开 Editor 手动拖入。

### 1.2 目标

实现「AI 生图 → 自动/手动导入 UE Content」全链路：

- **阶段一**：新增 `ue_import_asset` MCP Tool，AI 助手对话和工单均可通过自然语言触发导入
- **阶段二**（可选）：图片生成完成后，若 UE Editor 在线，自动触发导入

---

## 2. 架构决策

### 2.1 核心 vs 套件

| 组件 | 归属 | 原因 |
|------|------|------|
| `ue_import_asset` MCP tool | **核心** `backend/ue_mcp_server.py` | 通用能力，所有 UE 项目共用；现有 6 个 MCP tool 全在核心 |
| `art_assets.ue_path` 字段 | **核心** `backend/database.py` | 数据模型变更，全局生效 |
| `ue_editor.py` dispatch 分支 | **核心** `backend/agents/ue_editor.py` | 工单路由逻辑 |
| `/import-art` 命令（可选） | **套件** `config_packs/ue5-dev/` | 场景化工作流封装，调用核心 tool |

### 2.2 导入机制选型

UE 支持三种运行时资产导入方式：

| 方式 | 依赖 | 适合场景 |
|------|------|----------|
| `unreal.AssetImportTask` (Python API) | Editor 运行中 + Remote Execution 插件 | ✅ 本方案 |
| `UnrealEditor.exe -run=ImportAssets` | 命令行，不需要 Editor 启动 | 适合批量 CI |
| 拷贝 `.uasset` 二进制 | 无依赖 | 仅限已有 uasset |

选择 **`unreal.AssetImportTask`**：与现有 Blueprint/Level 生成走同一 `ue_python_bridge` 路径，代码复用度最高，风险最低。

### 3.1 `art_assets` 表新增字段

```sql

ALTER TABLE art_assets ADD COLUMN ue_path TEXT DEFAULT '';
-- 语义：资产导入 UE 后的内部路径，如 /Game/Textures/AI/T_IMG_abc12345
```

**注意**：`ue_path` 是全局字段，同一资产可能被导入多个 UE 项目的不同路径。当前阶段仅记录最近一次导入路径，后续可扩展为 `ue_imports` 关联表。

## 4. 核心实现：`ue_import_asset` MCP Tool

### 4.1 工具签名

文件：`backend/ue_mcp_server.py`

```python
@mcp.tool()
async def ue_import_asset(
    asset_id: str,
    project_id: str,
    ue_dest_path: str = "/Game/Textures/AI",
    asset_name: str = "",
    timeout: float = 60.0,
) -> str:
    """
    将 art_assets 库中的图片导入 UE 项目的 Content 目录，生成 Texture2D uasset。

    参数：
    - asset_id: art_assets 表中的资产 ID（如 IMG-xxxxxxxx）
    - project_id: 目标 UE 项目 ID（用于定位 UE Editor 实例）
    - ue_dest_path: UE 内部目标路径，如 /Game/Textures/UI（默认 /Game/Textures/AI）
    - asset_name: 导入后的资产名称，留空则用 asset_id 生成（T_{asset_id_短}）
    - timeout: 超时秒数（默认 60）

    返回 JSON：{"success": bool, "ue_path": str, "message": str}
    Editor 未启动时返回 success=false + 明确错误提示，不会挂起。
    """
```

### 4.2 实现逻辑

```python
async def _ue_import_asset_impl(
    asset_id: str,
    project_id: str,
    ue_dest_path: str = "/Game/Textures/AI",
    asset_name: str = "",
    timeout: float = 60.0,
) -> dict:
    from database import db
    from config import settings
    from engines.ue_python_bridge import run_python
    import json, pathlib

    # ── 1. 查资产 ──────────────────────────────────────────────
    row = await db.fetch_one("SELECT * FROM art_assets WHERE id = ?", (asset_id,))
    if not row:
        return {"success": False, "message": f"资产 {asset_id} 不存在"}

    # 构建绝对路径：ART_ASSETS_LOCAL_PATH + file_path
    rel_path = row["file_path"]        # 如 2d/generated/IMG-abc.png
    if not rel_path:
        # 降级：从 image_requests 取 result_path（绝对路径）
        img_req = await db.fetch_one(
            "SELECT result_path, result_url FROM image_requests WHERE id = ?", (asset_id,)
        )
        if img_req and img_req.get("result_path"):
            abs_path = img_req["result_path"]
        elif img_req and img_req.get("result_url"):
            # 只有远端 URL，无本地文件，无法导入
            return {"success": False, "message": "资产无本地文件，无法导入 UE（仅有远端 URL）"}
        else:
            return {"success": False, "message": "资产无本地路径"}
    else:
        base = settings.ART_ASSETS_LOCAL_PATH
        abs_path = str(pathlib.Path(base) / rel_path) if base else rel_path

    abs_path = abs_path.replace("\\", "/")
    if not pathlib.Path(abs_path).exists():
        return {"success": False, "message": f"本地文件不存在：{abs_path}"}

    # ── 2. 确定资产名 ──────────────────────────────────────────
    if not asset_name:
        short_id = asset_id.replace("IMG-", "").replace("-", "")[:8]
        asset_name = f"T_{short_id}"

    # ── 3. 构造 UE Python 导入代码 ────────────────────────────
    ue_full_path = f"{ue_dest_path.rstrip('/')}/{asset_name}"
    import_code = f"""
import unreal

task = unreal.AssetImportTask()
task.filename = r"{abs_path}"
task.destination_path = "{ue_dest_path}"
task.destination_name = "{asset_name}"
task.automated = True
task.replace_existing = True
task.save = True

result = unreal.AssetToolsHelpers.get_asset_tools().import_asset_tasks([task])

# 验证结果
imported = unreal.EditorAssetLibrary.does_asset_exist("{ue_full_path}")
print(f"IMPORT_OK={imported}")
print(f"UE_PATH={ue_full_path}")
"""

    # ── 4. 执行（需 Editor 在线）────────────────────────────────
    result = await run_python(import_code, project_id=project_id, timeout=timeout)

    if not result.get("success"):
        err = result.get("error", "未知错误")
        if "no_node" in err:
            return {"success": False, "message": "UE Editor 未启动或 Remote Execution 未开启，请先启动 Editor"}
        return {"success": False, "message": f"导入失败：{err}"}

    stdout = result.get("stdout", "") + result.get("result", "")
    if "IMPORT_OK=True" not in stdout:
        return {"success": False, "message": f"导入未确认成功，输出：{stdout[:200]}"}

    # ── 5. 回写 art_assets.ue_path ─────────────────────────────
    await db.execute(
        "UPDATE art_assets SET ue_path=?, last_used_at=? WHERE id=?",
        (ue_full_path, __import__("utils").now_iso(), asset_id),
    )

    return {
        "success": True,
        "ue_path": ue_full_path,
        "local_path": abs_path,
        "message": f"已导入 {asset_name} → {ue_full_path}",
    }


@mcp.tool()
async def ue_import_asset(
    asset_id: str,
    project_id: str,
    ue_dest_path: str = "/Game/Textures/AI",
    asset_name: str = "",
    timeout: float = 60.0,
) -> str:
    """（见上方文档字符串）"""
    result = await _ue_import_asset_impl(
        asset_id, project_id, ue_dest_path, asset_name, timeout
    )
    return json.dumps(result, ensure_ascii=False)
```

```python
async def _do_import_asset(self, context: Dict[str, Any]) -> Dict[str, Any]:
    """处理资产导入工单：从 context 提取 asset_id 列表，批量调 ue_import_asset tool"""
    from engines.ue_python_bridge import run_python
    
    project_id = context.get("project_id", "")
    asset_ids = context.get("asset_ids", [])          # 支持批量
    ue_dest_path = context.get("ue_dest_path", "/Game/Textures/AI")

    if not asset_ids:
        # 尝试从描述中解析 IMG- ID
        import re
        desc = context.get("description", "")
        asset_ids = re.findall(r"IMG-[a-f0-9]{8}", desc)

    if not asset_ids:
        return {"status": "error", "message": "工单中未找到可导入的资产 ID（需包含 IMG-xxxxxxxx 格式）"}

    results = []
    for aid in asset_ids:
        from ue_mcp_server import _ue_import_asset_impl
        r = await _ue_import_asset_impl(
            asset_id=aid,
            project_id=project_id,
            ue_dest_path=ue_dest_path,
        )
        results.append(r)

    ok = [r for r in results if r.get("success")]
    fail = [r for r in results if not r.get("success")]

    return {
        "status": "success" if ok else "error",
        "imported": [r["ue_path"] for r in ok],
        "failed": [r["message"] for r in fail],
        "message": f"导入完成：{len(ok)} 成功，{len(fail)} 失败",
    }
```

```python
async def _maybe_import_to_ue(req: dict, result_path: str) -> None:
    """
    图片生成完成后，检测 UE Editor 是否在线；若是，自动导入。
    失败时静默忽略（不影响主流程）。
    """
    try:
        project_id = req["project_id"]
        # 检查项目是否为 UE 项目
        from database import db as _db
        proj = await _db.fetch_one(
            "SELECT uproject_path FROM projects WHERE id = ?", (project_id,)
        )
        if not proj or not proj.get("uproject_path"):
            return  # 非 UE 项目，跳过

        # 检查 Editor 是否在线（快速探测，3秒超时）
        from engines.ue_python_bridge import run_python
        probe = await run_python("print('online')", project_id=project_id, timeout=5.0)
        if not probe.get("success"):
            logger.info("UE Editor 离线，跳过自动导入: project=%s", project_id)
            return

        # 触发导入（后台任务，不阻塞）
        import asyncio
        req_id = req["id"]
        asyncio.create_task(
            _ue_import_asset_impl_from_processor(req_id, project_id)
        )
        logger.info("已触发 UE 自动导入: asset=%s project=%s", req_id, project_id)
    except Exception as e:
        logger.debug("UE 自动导入检测失败（已忽略）: %s", e)


async def _ue_import_asset_impl_from_processor(req_id: str, project_id: str) -> None:
    try:
        from ue_mcp_server import _ue_import_asset_impl
        result = await _ue_import_asset_impl(
            asset_id=req_id,
            project_id=project_id,
            ue_dest_path="/Game/Textures/AI",
        )
        logger.info("UE 自动导入结果: %s → %s", req_id, result.get("message"))
        # 推 SSE 通知前端
        from events import event_manager
        await event_manager.publish_to_project(project_id, "ue_asset_imported", {
            "asset_id": req_id,
            "ue_path": result.get("ue_path", ""),
            "success": result.get("success", False),
            "message": result.get("message", ""),
        })
    except Exception as e:
        logger.warning("UE 自动导入执行失败: %s", e)
```

## 9. 错误处理策略

| 错误场景 | 处理方式 | 用户可见信息 |
|----------|----------|-------------|
| Editor 未启动 | 检测 `no_node` 返回，提示启动 | "UE Editor 未启动，请先在项目页面启动 Editor" |
| 本地文件不存在 | 检查 `pathlib.Path.exists()` | "资产无本地文件，建议先刷新资产库" |
| 仅有远端 URL | 尝试先下载再导入（或提示） | "资产仅有远端 URL，请配置 ART_ASSETS_LOCAL_PATH 后重试" |
| 目标路径非法 | 验证 `/Game/` 前缀 | "UE 路径须以 /Game/ 开头" |
| 导入后验证失败 | 检查 `IMPORT_OK=False` | "导入命令执行但未确认成功，请手动检查 Editor Content Browser" |
| Remote Execution 超时 | timeout 参数控制 | "导入超时（{timeout}s），可能正在处理大文件，稍后重试" |
