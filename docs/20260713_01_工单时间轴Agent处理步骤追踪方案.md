# 工单时间轴 Agent 处理步骤追踪方案

**创建日期**: 2026-07-13  
**状态**: 待实现  
**前置文档**: [20260630_01_Skill_Workflow_时间轴显示方案.md](./20260630_01_Skill_Workflow_时间轴显示方案.md)  
**背景**: 工单进行中时，Agent 处理经过 SOP 调度、skill 注入、LLM 推理等多个步骤，但时间轴只显示粗粒度的 `thought_start/thought_done`，无法反映 Agent 内部执行的子步骤进展。

---

## 一、三种来源的区别（关键澄清）

| 来源 | 定义内容 | 已追踪 | 可用于方案C |
|---|---|---|---|
| **SOP YAML** (`_core.yaml`, `default_sop.yaml`) | 宏观阶段：`trigger_on → success_status`，每个阶段对应一个 Agent.action | ✅ `thought_start/done` 已覆盖 | 否（已有） |
| **Skill .md 文件** (`## Workflow` 节) | LLM 行为指令，只影响提示词；LLM 按步骤推理，代码层无感知 | ❌ | 否（无代码执行） |
| **Agent Python action 代码** (`dev.py`, `architect.py` 等) | 实际调用序列：读上下文 → LLM 生成 → 写文件 → 编译验证 | ❌ 当前无打点 | ✅ 方案C的打点位置 |

**结论**：方案C的步骤标签来自 **Agent action 代码中人工添加的打点**，步骤名称可以手动对齐 skill .md 的描述，但数据源是代码，不是 .md 解析。

---

## 二、三种方案对比

### 方案 A：静态计划展示（Skill .md 解析）

6月30日方案的核心思路，接单时解析 active skills 的 `## Workflow` 节，写入 `skill_workflow_start` 日志，前端渲染为"预期步骤列表"。

- **优点**：不改 Agent 代码
- **缺点**：只是 skill 定义的"计划"，不是实际执行追踪；不知道当前走到哪步
- **改动范围**：orchestrator + skills/loader + 前端渲染
- **参考实现**：详见 [20260630_01](./20260630_01_Skill_Workflow_时间轴显示方案.md) 第三节

---

### 方案 B：REACT 工具调用透出

REACT 模式 Agent（DevAgent 等）的每次工具调用已有 `ToolDoneEvent`（含 `duration_ms`），目前只写 `tool_audit_log`，改成**同时写 `ticket_logs`**（新 action 类型 `react_tool`）。

**效果示例**：
```
[时间轴]
  ● DevAgent 接单
  ├── 🔧 read_files  (234ms)
  ├── 🔧 glob        (45ms)
  ├── 🔧 write_file: src/Foo.cpp  (1230ms)
  ├── 🔧 shell: tsc --noEmit      (3200ms)
  ● DevAgent 完成
```

**改动范围**：
- `backend/orchestrator.py` 或 `backend/hooks/builtin.py`：在 `ToolDoneEvent` handler 中追加写 `ticket_logs`
- 前端 `renderLogItem`：加 `react_tool` 渲染分支（工具名 + 耗时）

**局限**：只覆盖 REACT 模式；BY_ORDER / SINGLE 模式（ArchitectAgent、ReviewAgent 等）无效。

---

### 方案 C：Agent 代码主动打点（最准确）

在 **Agent action 代码的关键节点**调用 `emit_step(step_name)`，写 `skill_step_start` / `skill_step_done` 类型日志。

**效果示例**：
```
[时间轴]
  ● DevAgent 接单
  ├── ⏱ [1/4] 读取代码库 · 开始
  ├── ✅ [1/4] 读取代码库 · 完成  (0.8s)
  ├── ⏱ [2/4] AI 生成代码 · 开始
  │   └── 🤖 LLM 调用 (claude-sonnet, 3.2s, 1200→800 tokens)
  ├── ✅ [2/4] AI 生成代码 · 完成  (3.2s)
  ├── ⏱ [3/4] 写入文件 · 开始
  ├── ✅ [3/4] 写入文件 · 完成  (0.3s)
  ├── ⏱ [4/4] 编译验证 · 开始
  ├── ✅ [4/4] 编译验证 · 完成  (8.1s)
  ● DevAgent 完成
```

**BaseAgent 新增 helper**：
```python
# backend/agents/base.py
async def emit_step(
    self,
    step_name: str,
    phase: str = "start",          # "start" | "done" | "error"
    step_index: int = 0,
    step_total: int = 0,
    duration_ms: int = 0,
):
    """在 ticket_logs 写入 skill_step_start / skill_step_done 日志"""
    action = "skill_step_start" if phase == "start" else "skill_step_done"
    await self._log(
        project_id=self._current_project_id,
        requirement_id=self._current_requirement_id,
        ticket_id=self._current_ticket_id,
        agent_type=self.__class__.__name__,
        action=action,
        from_status=None, to_status=None,
        message=f"[{step_index}/{step_total}] {step_name}",
        detail_data={
            "step_name": step_name,
            "step_index": step_index,
            "step_total": step_total,
            "phase": phase,
            "duration_ms": duration_ms,
        }
    )
```

**DevAgent 打点示例**（`backend/agents/dev.py`）：
```python
async def _do_develop(self, context):
    step_total = 4

    # 步骤 1：读取代码库
    await self.emit_step("读取代码库", phase="start", step_index=1, step_total=step_total)
    existing_code = await read_existing_code(context)
    await self.emit_step("读取代码库", phase="done", step_index=1, step_total=step_total)

    # 步骤 2：AI 生成代码
    await self.emit_step("AI 生成代码", phase="start", step_index=2, step_total=step_total)
    result = await action_node.run(context)
    await self.emit_step("AI 生成代码", phase="done", step_index=2, step_total=step_total)

    # 步骤 3：写入文件
    await self.emit_step("写入文件", phase="start", step_index=3, step_total=step_total)
    await write_files(result.files)
    await self.emit_step("写入文件", phase="done", step_index=3, step_total=step_total)

    # 步骤 4：编译验证（如有）
    if context.get("sop_config", {}).get("engine_compile"):
        await self.emit_step("编译验证", phase="start", step_index=4, step_total=step_total)
        await run_compile(context)
        await self.emit_step("编译验证", phase="done", step_index=4, step_total=step_total)
```

**改动范围**：
- `backend/agents/base.py`：新增 `emit_step()` helper（~20行）
- 各 Agent action 文件逐步添加打点，优先级：DevAgent > ArchitectAgent > TestAgent > ReviewAgent

## 四、日志 detail 字段规范

### `react_tool`（方案B）
```json
{
  "tool_name": "write_file",
  "args_hint": "src/Foo.cpp",
  "duration_ms": 1230,
  "success": true
}
```

### `skill_step_start` / `skill_step_done`（方案C）
```json
{
  "step_name": "AI 生成代码",
  "step_index": 2,
  "step_total": 4,
  "phase": "done",
  "duration_ms": 3200
}
```

## 五、前端时间轴 tier 分类调整

| action 类型 | tier | 默认可见 |
|---|---|---|
| `react_tool` | secondary | 折叠，点"详细"展开 |
| `skill_step_start` | secondary | 折叠 |
| `skill_step_done` | primary（若有耗时 >1s 或 error） | 可见 |
| `skill_step_done`（快速步骤） | secondary | 折叠 |
