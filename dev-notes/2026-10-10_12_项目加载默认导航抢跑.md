# 进项目后立刻点外部会话，加载完被拽回看板

2026-10-10

## 现象

第一次进项目页，点侧栏「外部会话」，es 面板开始加载；加载成功后主舞台自动跳回看板页
（侧栏两个 nav 同时亮着）。

## 根因：项目数据加载完成后的默认导航抢跑

`showProjectDetail` → `loadProjectDetail()`（async，不 await）→ 其 API 往返结束后**无条件
`switchTab('board')`**（"加载默认 tab"）。

时间线：

1. 进项目，`loadProjectDetail` 的 `/projects/{id}` 请求在飞；
2. 用户手快点了「外部会话」→ `switchTab('external-sessions')` → es Tab 打开、`_esRefresh`
   开始拉列表（此时 `state.currentPage = 'external-sessions'`、`mainActiveId = es:panel`）；
3. 项目数据响应回来 → `switchTab('board')` → `notifyPage('board')` 把 `mainActiveId` 清空
   → 主舞台跳回看板页面视图。

这个竞态影响所有"进项目后立刻点任意导航"的场景，es 只是最容易踩的（用户进项目直奔它）。

## 修复

`loadProjectDetail` 尾部的默认导航加条件：**用户还停在 board（且没开文档 Tab）才切**。
用 `adsShell.getState()` 读 `currentPage` / `mainActiveId`：

- `currentPage !== 'board'` → 用户已点其他栏目，跳过；
- `mainActiveId` 非空 → 用户开了文档 Tab，跳过；
- 否则维持原行为（进项目默认落看板 + loadRequirementFilter 不受影响）。

正常进项目（不点）→ currentPage 仍是 'board' → 行为不变。

## 验证边界

- `node --check` 过；未跑浏览器实测。
- `loadProjectDetail` 只有 `showProjectDetail` 一个调用方，守卫在所有调用点语义一致
  （"用户已经走了就别拽回来"）。
