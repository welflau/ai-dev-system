# 外部会话图片 Tab：滚轮缩放 + 左键拖动 + 双击复位

2026-10-10

## 起因

图片 Tab（外部会话里点图片打开，`type === 'image'`）原来只有一个 click 切换 `max-height`
的土办法，没有缩放/平移，看大图不方便。需要常规图片查看器操作：滚轮缩放、左键拖动平移。

## 实现

`frontend/app.js` + `frontend/styles.css`：

1. **`_loadMainTabContent` 的 image 分支**：容器从 `overflow:auto` 改成 `overflow:hidden` +
   `position:relative`，去掉 img 的 click 切换 hack，改为调 `_esInitImageViewer(container)`。
2. **`_esInitImageViewer`**（新增，顶层函数，放在 `_es*` 块末尾）：
   - 状态：`scale` / `tx` / `ty`，`scale=1` 即"适配窗口"（CSS 的 `max-width/max-height` 原始
     尺寸），往上放大到 `MAX=12`，往下不再缩（`MIN=1`）。
   - 渲染：`img.style.transform = translate(tx,ty) scale(scale)`，`transform-origin` 用默认
     （图片中心）。容器 flex 居中、`overflow:hidden` 裁剪。
   - 滚轮：`wheel` 监听 `{ passive:false }` + `preventDefault`（阻止面板外滚），`factor =
     Math.pow(1.0015, -deltaY)` 归一化不同浏览器/触控板的 deltaY，以光标为锚点缩放：
     `tx = mx - (mx - tx) * k`（k = 新scale/旧scale），光标下像素基本不动。
   - 左键拖动：pointerdown(button 0) 记起点 → pointermove 更新 `tx/ty` → pointerup/cancel
     结束，`setPointerCapture` 保证拖出容器不丢；`touchAction:none` 让触屏/触控板也走拖动。
   - 双击：复位 `scale=1, tx=ty=0`。
   - 光标反馈：拖动中 `grabbing`；放大后 `grab`；适配态 `zoom-in`。
   - 百分比角标 `.es-image-zoom`：右下角显示缩放比例，适配态隐藏。
3. **`styles.css`**：新增 `.es-image-zoom`（absolute 定位，不参与 flex 居中，避免把图片挤偏）。

## 关键点

- `.main-ws-img` 是 flex 居中容器，缩放角标若作为普通子元素会参与 flex 布局、把图片挤偏，
  所以必须 `position:absolute`（绝对定位子元素不参与 flex 布局）。
- 缩放用 transform 叠加，不改变图片布局尺寸，flex 始终按"适配尺寸"居中，不会出现缩放时
  布局跳动。
- 没动 `_fillFilePane` 里的文件图片预览（`type === 'file'` 的 `.main-ws-img`），它仍是原来的
  静态展示，不在本次范围。

## 验证边界

- `node --check` 语法过，未跑浏览器实测。
- **触控板双指缩放 vs 滚轮**：双指捏合在部分环境下也走 wheel + ctrlKey，此处按普通滚轮
  处理，未专门处理 `ctrlKey` 分支。
- **缩放后图片可能被拖到完全离开可视区**（放大后拖很远），双击可复位，未做"拖回边界"夹紧。
- **大图性能**：transform 缩放走合成层，一般流畅；超大原图仍受浏览器解码上限约束。
