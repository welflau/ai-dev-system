## 本阶段目标

更新 `ue5-dev` 套件的 `/ue-asset` 命令，接入阶段一建立的 `ue_import_asset` MCP tool，并补充"导入已有资产"和"列出可导入资产"两种模式。

---

## 改动文件

### `backend/config_packs/ue5-dev/shared/commands/ue-asset.md`

**旧内容**：引用旧脚本路径（`generate_texture_script`、`ue_python_script`），与当前系统脱节。

**新内容**：三种模式，全部基于当前系统能力：

| 模式 | 命令 | 调用链 |
|------|------|--------|
| `generate` | `/ue-asset generate <描述>` | `POST /api/image-gen` → 轮询 → `ue_import_asset` MCP tool |
| `import` | `/ue-asset import <asset_id>` | 直接调 `ue_import_asset` MCP tool |
| `list` | `/ue-asset list` | `GET /api/art-assets?source=ai_generated` |
