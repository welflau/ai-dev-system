## 一、进度面板静默感知（`f62142f`）

**问题**：`run_engine_compile` 等长耗时任务静默运行，用户不知是卡住还是正常处理。

**修复**：

- "暂无输出" → "处理中…"

## 三、报错消息文件路径可点击（`5336762`）

**问题**：编译错误中的 `file.cpp(89):` 是纯文本，找不到对应文件。

**修复**：`_linkifyErrors(text)` 解析三种格式并转为可点击链接：
- MSVC: `file.cpp(123):`
- GCC/Python: `file.py:45:12:`
- Python: `File "test.py", line 45`

点击调用 `openRepoFileFromChat()` 跳转到仓库文件查看器。

**应用位置**：进度面板 progress-latest-log + 时间轴日志展开区错误详情行。

## 四、LLM 推理日志 vs 本地工具日志区分（`671dd3a`）

**问题**：`thought_start` 日志名称暗示 LLM 调用，但 `run_engine_compile` 是纯本地 UBT，让用户误判。

**修复**：

- 前端 `LAYER_ACTIONS` 加 `tool_start`/`tool_done` 快捷渲染（🔧 本地工具执行/完成）
