# DevLog：ue_lint R15 Cast 判空规则

> 日期：2026-11-06
> 关联：R9-R14 生命周期资源检查
> 位置：`plugins/ue5/actions/ue_lint/rules.py`

## 目标

延续生命周期资源检查，落地 R15：Cast 结果未判空直接解引用。

## 设计动机

`Cast<T>(X)` 类型不符时返回 nullptr，直接 `->` 解引用会崩溃。这是 UE 常见崩溃场景，与 R10（空引用）相关但更聚焦——R10 管「非 this 指针访问」，R15 管「Cast 返回值的解引用」。

## 设计

- `_RE_CAST_DEREF`：匹配 `Cast<T>(X)->` 直接解引用
- 正则本身即精确区分：
  - `Cast<T>(X)->DoThing()` → 命中（危险）✅
  - `if (Type* P = Cast<T>(X)) { P->... }` → Cast 后是 `)`，不命中 ✅
  - `CastChecked<T>(X)->` → `\bCast\s*<` 不匹配 `CastChecked`（后跟 `Checked` 非 `<`），自动排除 ✅

**关键决策**：
1. **warning 级别**：开发者确信类型匹配时直接解引用是合理的。
2. **正则天然精确**：无需额外守卫检查，`Cast<T>(X)->` 模式本身就是"未判空解引用"的特征。

## 验证（6 场景全过）

| 场景 | 结果 |
|---|---|
| Cast 直接解引用 | ✅ 报 warning |
| if 判空写法 | ✅ 不报 |
| CastChecked | ✅ 不报（自动排除） |
| 逃生注释 | ✅ 不报 |
| 无 Cast | ✅ 不报 |
| 非 C++ 文件 | ✅ 跳过 |

## 收尾

ue_lint 规则集现为 R1-R15。生命周期资源检查完整闭环：委托配对(R9)/空引用(R10)/递归(R11)/Timer配对(R12)/弱引用(R13)/UPROPERTY(R14)/Cast判空(R15)。
