# H5 安装过程进时间轴，任务 Log 可点

2026-10-23

前作：`dev-notes/2026-10-23_02_H5试玩门禁不对仓库另开沙箱.md`

## 起因

`h5_playtest` 缺 Playwright / Chromium 时已经会当场 `pip install` + `playwright install chromium`，但只打 logger。工单时间轴看不见安装过程，后台任务面板也没有对应记录，点不开「📟 后台记录」。

TestAgent 是直接 `action.run(context)`，不走 `run_action` 的 POST_TOOL_USE，所以 `offer_command_record` + `command_record_hook` 这条链接不上。

## 实现

`command_log.record_traced_command`：给不经过 hook 的命令成对写入 `ticket_logs`（`command_run`）和 `ticket_command_log`，`detail.task_id` ↔ 记录 id。前端时间轴据此渲染「📟 后台记录」，点开拉 `/ticket-command-logs/{id}`。

`h5_playtest`：

- 真要装 Playwright 时打 `skill_step`（开始 / 完成 / 失败），完成行挂 `task_id`
- `npm install` 同样打步骤 + 命令记录
- `vite build` 记命令（详细日志）
- 每条命令的 argv / exit_code / 输出进 `ticket_command_log`

时间轴 skill_step 行也显示「📟 后台记录」。`log_added` 时如果抽屉开着会刷新时间轴。

## 没做

没把 hook 重构成调用 `record_traced_command`（两条路径并行，行为对齐即可）。没改 SOP，没自动 unblock 已 blocked 的工单。

相关测试：`tests/plugins/test_h5_plugin.py`。
