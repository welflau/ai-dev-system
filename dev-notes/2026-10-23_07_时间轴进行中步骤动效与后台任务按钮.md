# 时间轴进行中步骤动效 + 后台任务按钮

2026-10-23

前作：`dev-notes/2026-10-23_06_H5安装过程进时间轴与命令记录.md`

## 起因

`fix_issues` 跑 `[2/3] 反思失败根因` 时，`skill_step_start` 在 `_SECONDARY_ACTIONS` 里被分到次级日志。主时间轴只剩 `[1/3] 拉取重试上下文 5ms`，底下空着，看不出正在跑第 2 步。而且第 1 步本身不写文件，却挂了「无产出文件」标签；有后台任务/输出的步骤也缺跳转按钮。

## 实现

`tickets.py::_promote_in_flight_steps`：

- 工单不在终态时，看最近一次 `thought_start / tool_start / assign` 之后的尾段
- 尚未收到对应 `skill_step_done / skill_step_error` 的那条 `skill_step_start`，提为 `_tier = "primary"` + `_running = True`
- 步骤一旦完成，`skill_step_done` 落库，`skill_step_start` 自动退回次级日志，主轴不留两行

前端 `app.js` / `styles.css`：

- `_running` 步骤渲染旋转 `⟳`、蓝色脉冲左边框、「进行中…」徽标
- 所属阶段头同步加蓝点脉冲与「处理中」徽标
- 步骤或命令有对应后台任务（`TCMD-*` 真命令记录，或带文件/输出摘要的合成任务）时，显示 **📟 后台任务** 按钮，点击跳到后台任务面板并选中该任务；正在跑的步骤点击直接打开该工单的后台任务面板
- 「拉取重试上下文」「反思失败根因」这类本来就不写文件的步骤，不再误标「无产出文件」

`h5_typecheck` / `h5_playtest` / `self_test` / `reflect`：

- `tsc --noEmit` 写入 `ticket_command_log`，步骤与 `complete/reject` 都挂 `task_id`
- `vite build` 的 `task_id` 透传到试玩步骤与 `complete/reject`
- `自测验证`、`反思失败根因` 把检查项/根因摘要写进步骤 `output_summary`，在后台任务面板也能点开看详情

相关测试：`tests/plugins/test_h5_plugin.py`、`_test_command_log_ui.js`。
