# 外部会话图片点击改为应用内主舞台 Tab 显示

2026-10-10

## 起因

外部会话（Cursor）消息里的图片缩略图，之前是 `<a target="_blank">` 直接开新浏览器窗口看原图。
用户要求：点开能在应用内开一个 Tab 页显示。

## 改动

复用主舞台 Tab 系统（`adsShell`），新增一种 `type:'image'` 的 Tab，共四处：

1. `frontend/app.js` `adsShell.openMain` — 新增 `image` 分支：按 `image:<sessionId>:<uuid>` 登记
   去重（一张图一个 Tab，重复点同一个图不会开两个）。
2. `_loadMainTabContent` — 新增 `image` 挂载分支（早返回，不走通用 文件/树/findbar 骨架）：
   头部一条 pane-header 放标题，主体复用 `.main-ws-img` 居中展示。
3. `_renderMainWorkspace` — tab 图标映射加 `🖼`。
4. `_esRenderImages` — `<a target="_blank">` 改成 `<img onclick="adsShell.openMain({type:'image',...})">`，
   光标 `cursor:zoom-in`。

## 两个实现细节

- **标题不进 onclick 参数**：会话标题可能含单引号，而 `escHtml`（textContent→innerHTML）
  **不转义引号**，拼进 `onclick="...title:'...'"` 的 JS 字符串有注入/断串风险。所以 Tab 标题在
  `openMain` 内部用 `uuid 前 8 位` 生成（`图片 xxxxxxxx`），onclick 里只传
  sessionId/uuid/projectId（都是 uuid 格式，安全）。
- **大图查看**：图片 URL 和缩略图同一个端点。容器 `overflow:auto` + 图片 `max-height:none`
  （内联覆盖 `.main-ws-img img` 的 `calc(100vh - 220px)`），完整尺寸可滚动；点击图片在
  「适应屏高 ↔ 原始大小」之间切换。

## 验证边界

- `node --check` 语法过。
- 未跑浏览器实测：Tab 去重、切项目后 projectId 是否还正确挂载，需要手点验证。
  `openMain` 里 `existing.projectId = tab.projectId || currentProjectId` 每次点击都会刷新，
  理论上切项目后重新点图会用新项目的 API 路径（旧会话图片本来就属于旧项目的 workspace）。
- 内联 `onclick` 引用 `adsShell` 是既有成熟用法（文件 Tab 的 📄 按钮就这么干，app.js:1437）。
