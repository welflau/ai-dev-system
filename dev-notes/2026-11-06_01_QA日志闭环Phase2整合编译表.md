# DevLog：QA 日志闭环 Phase 2 — 整合编译表

> 日期：2026-11-06
> 关联：`docs/20261105_07_QA日志闭环设计方案.md`（Phase 2）

## 目标

把 `engine_compile`（编译）与 `play_test`（试玩）两个阶段的引擎日志整合成统一 QA 报告（编译表 + 场景表 + 问题表）。

## 探索发现

1. UE QA 链是**两阶段**：`engine_compile`（DevAgent → UECompileCheckAction，priority 95）→ `play_test`（TestAgent → UEPlaytestAction，priority 85）。
2. 两个 Action 都**已把引擎日志解析成结构化结果**：
   - `UECompileCheckAction` → `errors[{file,line,code,category,severity,msg}]` + warnings + summary
   - `UEPlaytestAction` → `tests[{name,result,errors}]` + summary + screenshots
3. **关键发现**：`_do_run_engine_compile`（dev.py:74）只是 `return result.to_dict()`，**不写 artifact**。server.log 里 `run_engine_compile 完成 → files=0` 印证了 compile_log 从未落库。
4. `artifacts/kinds.yaml` 已定义 `compile_log` kind（storage: file），但 fragment 路径没写它。
5. `ArtifactStore`（artifacts/store.py）提供 `put`（写文件+登记）/ `list`（查）/ `read_text`（读）API，可直接用。

## 方案

1. **dev.py**：`_do_run_engine_compile` 编译完成后写 `compile_log` artifact（JSON）。
2. **test.py**：`run_playtest` 生成报告前回溯读 `compile_log`，合并进报告。
3. **报告渲染**：`_render_playtest_report` 增加「编译表」段 + 综合结论（编译失败 → 整体 FAIL）。

---

## 实施过程

### 改动 1：`dev.py` — 编译后写 compile_log artifact

- `_do_run_engine_compile`（dev.py:74）：编译完成后调 `_persist_compile_log(context, d)`。
- 新增 `_persist_compile_log`（dev.py:89）：把 `errors/warnings/summary/status/exit_code/duration_ms/command` 序列化 JSON，经 `ArtifactStore().put(kind="compile_log", filename="compile_log.json")` 落库。
- 写入失败只 warning 不阻断（compile_log 是 play_test 报告的可选增强）。

### 改动 2：`test.py` — 回溯读 compile_log + 合并报告

- `run_playtest`（test.py:76）：生成报告前调 `_load_compile_log(context)`，把 compile 数据传给 `_render_playtest_report`。
- 新增 `_load_compile_log`（test.py:113）：`ArtifactStore().list(ticket_id, kinds=["compile_log"], latest_per_kind=True)` + `read_text` + JSON 解析；读不到返回 None。
- `_render_playtest_report` 扩展（test.py:141）：
  - 新增「编译表」段（文件/行/错误码/分类/信息），编译通过显示 ✅。
  - 综合结论：编译失败 → 整体 FAIL + 评级 F（编译不过直接判死）。
  - 「试玩表」独立成段（原汇总表改名）。
  - 问题清单分类：`[编译]` / `[试玩]` 前缀。

### 关键设计决策

- **降级安全**：compile_log 读不到 → 报告降级为仅试玩表（Phase 1 行为），不报错。
- **编译失败判死**：`compile_failed = bool(errors) or status in ("error", "compile_failed")` → FAIL + F，符合「编译不过没必要看测试」的语义（engine_compile fragment 也注释了「编译不过没必要审代码」）。
