# 全局页侧边栏与常驻工具条、G_ArtRes 静态挂载、聊天全屏切项目空白修复

2026-10-30

## 起因

三个独立问题在本轮一并处理：

1. **全局页无导航入口**：`#projectListPage`（“我的项目”）没有侧边栏，全局知识库（G_Knowledge）、全局资产库（G_ArtRes）、全局 Agent 注册表这些天然全局的数据，入口被藏在项目侧边栏子项和设置页 Tab 里，全局页看不到。
2. **资产缩略图不可见**：`art_assets.file_path` 是相对 G_ArtRes 根目录的路径，但后端没有 G_ArtRes 的静态挂载，前端 `window.artAssetsBase` 从未赋值，资产墙只对 svg 拼了个坏链、png/jpg 直接显示 emoji。
3. **聊天全屏切项目后消息区空白**：全屏聊天里通过标题下拉切项目，消息区完全空白，退出全屏才恢复。

## 实现

### 1. 全局页侧边栏 + 常驻工具条

- `frontend/index.html`：`#projectListPage` 包进 `.global-layout`，顶部 `.global-toolbar`（常驻横跨全宽：左侧收起按钮，右侧随面板切换的标题/按钮组 `gt-panel-title`/`gt-panel-actions`），下方 `.global-main` = 侧栏导航（项目/知识库/资产库/Agent）+ `.global-content`（4 个面板）。
- 交互要点：**收起只收导航，工具条与按钮纹丝不动**（按钮永远在原位置）。面板标题/按钮上工具条，内容区不再有第二行 page-header。
- `frontend/app.js`：`toggleGlobalSidebar`/`setGlobalSidebarCollapsed`/`initGlobalSidebarState`/`switchGlobalPanel` + 3 个全局渲染函数（`renderGlobalKnowledge` → `/knowledge/global`、`renderGlobalAssets` → `/art-assets`、`renderGlobalAgents` → `/agents`）。全部用新 DOM id，不复用设置页函数（所有 `.tab-content` 挂在 `#projectPage`，全局页无法复用 `switchTab`）。
- 方案文档：`docs/20261029_01_全局页面左侧导航与全局作用域方案.md`。

### 2. G_ArtRes 静态挂载

- `backend/main.py`：挂载 `/art-res` → `ART_ASSETS_LOCAL_PATH`；新增 `ArtResGuardMiddleware` 拦截 `/art-res/private`、`/art-res/.git`、`/art-res/node_modules`（G_ArtRes 根目录下有 Naughty Dog 未授权角色模型等私有资产）。
- `backend/config.py`：**修复配置加载**——原来 `load_dotenv()` 从项目根启动时加载的是根目录 `.env`（只有基础 LLM 配置），`ART_ASSETS_LOCAL_PATH`/`GLOBAL_KNOWLEDGE_LOCAL_PATH` 等在 `backend/.env` 里读不到。改为用 `backend/.env` 覆盖全部非空变量。副作用：`LLM_MODEL` 从根目录旧值 `claude-sonnet-4-20250514` 修正为 `backend/.env` 的 `claude-sonnet-4-5`，`LLM_API_FORMAT` 从 `anthropic` 修正为 `cli`（backend/.env 本就是权威，此前仅 LIGHTAI key 被特殊强制覆盖）。
- `frontend/app.js`：`window.artAssetsBase = '/art-res/'`；全局资产墙 + 设置页资产墙缩略图从“仅 svg”扩到 `svg/png/jpg/jpeg/webp/gif/bmp` 都显示真图。

### 3. 聊天全屏切项目空白修复

- `frontend/app.js` `_switchProjectInFullscreen`：原为轻量路径（只改 `currentProjectId` + 重载聊天），补齐 `disconnectSSE`/`connectSSE`/`clearLogPanel`/`loadLogPanelHistory`（SSE 残留会串台、日志面板还是旧项目）；刻意不调 `enterProject`（会把全屏退掉）、不调 `showPage`（全屏下面板盖住页面）。
- **空白兜底**：`_switchProjectInFullscreen` 与 `_switchToGlobalChat` 延迟 800ms 检查消息区，若连欢迎页/加载点/消息卡都没有（且非流式发送中）则 `_reloadChatForCurrentMode()` 补载。根因场景：刷新恢复流程未走完（`_chatWsPersistReady=false`）时切项目 → `_updateChatPanelForContext` 走“只清空不加载”分支，恢复流程稍后的加载又因 context 已变被 stale 凭证拦截，无人再补载。
- 回归测试：`backend/_test_fullscreen_project_switch.js`（静态断言 16 项）。

## 验证

- `node --check app.js` 通过；`python -m py_compile config.py main.py` 通过。
- `ArtResGuardMiddleware` 路径拦截 8 用例全过（`/art-res/private` 及子路径拦截、`private-x` 不误伤）。
- `ART_ASSETS_LOCAL_PATH` 现解析为 `F:\A_Works\G_ArtRes` 且存在（修复前从项目根启动为空）。
- `_test_fullscreen_project_switch.js` 16/16 通过。

## 遗留

- 前端为纯静态文件（后端 `/static` 挂载，no-cache），改动即时生效但需刷新页面验证；运行时视觉验证依赖启动前后端服务，本轮只做了静态断言 + 语法检查。
- 资产缩略图依赖 `source_url`（AI 生图临时 URL）与 `/art-res` 本地文件；`private/` 拦截已覆盖，但 G_ArtRes 根目录未来若新增其他敏感目录需同步补充 `ArtResGuardMiddleware._FORBIDDEN`。
- 聊天全屏切项目的空白根因是“恢复流程竞态”，兜底是延迟补载而非从机制上消除竞态；若复现请带 F12 Console 报错进一步定位。
