## 一、本阶段内容

### 1. 聊天关联工单 → Checkpoint

- `ChatRequest.ticket_id` 可选字段  
- `/projects/{pid}/chat/stream` 校验工单归属后写入 `project_context.ticket_id`  
- 前端主聊天 / 分屏：带上 `chatCurrentTicketId` 或 `_currentTimelineTicketId`  
→ 项目聊天里 Write/Edit 可归属到当前聚焦工单并拍快照

### 2. before_write 进详细日志

- `_classify_tier`：`checkpoint` + `trigger=before_write` → **secondary**  
- `ticket_start` / `phase_boundary` / `checkpoint_restore` / `revert` → **primary**（可「还原到此」）

### 3. 手动 GC

- `POST /api/projects/{pid}/checkpoints/gc`  
  body 可选：`{ "ttl_days": 14, "keep_active_writes": 50 }`  
- 返回删除的 checkpoint / files / blobs 统计

### 4. 还原文案与部分成功

- 时间轴还原确认标明「Checkpoint，不依赖 Git」  
- Toast：还原数 + 跳过 + 错误；取消回滚同样展示策略与计数  
- restore / cancel 日志带人可读 `message` 摘要

---

## 二、验收

1. 打开工单抽屉后在右侧 AI 聊天发消息并触发写文件 → 该工单有 before_write（详细日志）  
2. 主时间轴只见 ticket_start / phase_boundary / restore，写前快照在「详细日志」  
3. `POST .../checkpoints/gc` 返回 `ok` 与统计字段  
4. 故意缺 blob 或跳过大文件还原 → Toast 显示「跳过/错误」而非假成功
