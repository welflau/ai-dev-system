# 多 Agent 群聊黑板 Phase 1

2026-10-12

## 背景

群聊只有两版「并行盲答」：`/group`（单个 Agent 人格）和 `/group/all`（3 Agent 并发各自回复，
互不可见）。Phase 1 升级为「回合制辩论 + 共享黑板」，验证「互见 + 黑板」是否比并行盲答质量更高。

方案文档：`docs/20261012_01_多Agent群聊黑板架构方案.md`

## 改动

### 后端

- `database.py`
  - `chat_messages` 加两列：`speaker TEXT`（发言人）、`kind TEXT DEFAULT 'message'`（message/utterance/system）。
  - 新表 `chat_blackboards(session_id PK, project_id, state_json, version, updated_at)`。
- `api/chat.py`
  - `_save_chat_message` 加 `speaker` / `kind` 参数（落库）。
  - 黑板纯函数：`_empty_board` / `_load_blackboard` / `_save_blackboard`（upsert，version 自增）/
    `_apply_board_writes`（同 agent 同内容去重、非法分区忽略、op=remove 删除）/
    `_board_snapshot_text` / `_board_agent_prompt` / `_board_converger_prompt`。
  - 新端点 `POST /group/board` + `_group_board_generator`：
    - 轮内并行（`asyncio.gather`）、轮间串行，默认 2 轮 + 收敛器。
    - `llm_client.chat_json` 三态输出 `{public_message, thought, blackboard_writes}`；
      JSON 解析失败降级为「整段当公开发言、黑板写为空」。
    - SSE：`turn_begin / board_init / agent_thought / agent_message / board_update / converge / message_done / error`。
    - 发言落库 `action={"type":"group_agent_reply",...,"thought":...}`（刷新复用既有气泡还原），
      收敛小结 `kind="system"`。

### 前端

- 群聊 Tab 加「🧠 黑板群聊（回合制辩论）」开关（`_groupBoardMode` + `toggleGroupBoardMode`）。
- 无 @mention 且开关开 → `_sendGroupBoardStreaming`（fetch + ReadableStream 消费 SSE）；
  否则保持原 `/group/all`。
- `_renderBoardSummary`：黑板卡片 live 渲染 proposals/分歧/共识/产物。
- 新增 CSS：`.group-board-card / .group-board-thought / .group-board-converge / .board-sec / .board-item`。

## 关键取舍 / 偏差

- 气泡渲染已同时支持 `group_agent_reply` action 和 `speaker` 列（`_AGENT_MENTIONS` 提供 emoji/color），speaker 无 action 也能还原气泡。
- `thought` 双写：`action_data.thought`（直播独立思考条目）+ `thinking_json` 分组格式（刷新后走思考面板渲染）。
- GET 快照 / events 端点未做（Phase 3）。
- 前端 board 路径未传 `chat_session_id`，消息落到 `default` 会话（和 `/group` 一致；刷新还原靠该会话历史）。

## 卡死 bug（实测发现并修复）

- **现象**：OG 项目（PRJ-20260629，UE5 大仓库）发黑板群聊，`board_init` 渲染后无后续，后端事件循环被卡死
  （日志冻结、`/api/health` 等全不响应，持续数分钟）。
- **根因**：`_group_board_generator` 调了 `_build_project_context`，其内部 `sorted(repo_dir.rglob("*"))`
  会**遍历整个仓库树**（UE5 的 Content/Binaries/Intermediate 几十万文件），同步 I/O 阻塞事件循环。
  而黑板群聊的 prompt 根本用不到 project_context（只用 project.name/description/tech_stack）。
- **修复**：删掉 `_group_board_generator` 里这行无用调用。
- **连带修复（2026-10-12 追加）**：`_build_project_context` 本身的 `sorted(rglob("*"))` 也改成
  「惰性取满 100 个再 `all_files.sort()`」——`/group`、`/group/all`、主聊天路径共用它，
  一并消除隐患。实测 OG 项目 `_build_project_context` 从「卡死数分钟」降到 0.71s。

## 浏览器实测反馈修复（2026-10-13）

1. **主题过期**：黑板跨轮累积但 topic 停在首条消息（"主题: 你好" 配上新问题）。
   修复：generator 每轮 `board["topic"] = req.message[:80]`。
2. **Agent 名重复**：`[DevAgent] [DevAgent] ...` —— LLM 模仿快照 `[agent] content` 格式把自我前缀写进 content。
   修复：`_apply_board_writes` 剥离开头 `[writer]` 自我前缀（他人前缀保留，用于引用场景）。

`py_compile` + 前缀剥离单测通过，后端重启生效。
