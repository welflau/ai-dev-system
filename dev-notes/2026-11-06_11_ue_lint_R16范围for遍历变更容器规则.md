# DevLog：ue_lint R16 范围 for 遍历变更容器规则

> 日期：2026-11-06
> 关联：R9-R15 生命周期资源检查
> 位置：`plugins/ue5/actions/ue_lint/rules.py`

## 目标

延续生命周期资源检查，落地 R16：范围 for 遍历中变更容器。

## 设计动机

`for (X : Container)` 循环体内对 Container 调 `Remove`/`Add` 会令迭代器失效，导致未定义行为 / 崩溃。这是 C++/UE 常见且危险的 bug。

## 设计

- `_RE_FOR_RANGE`：匹配 `for (... : Container)` 提取容器名
- `_find_brace_block`：花括号匹配定位循环体（复用 R10/R11 的块定位思路）
- 循环体内搜「同名容器」的变更操作（`Remove`/`RemoveAt`/`RemoveAll`/`RemoveSingle`/`RemoveSwap`/`Add`/`AddUnique`/`Empty`）

**关键决策**：
1. **warning 级别**：某些场景（如遍历副本）是安全的，保守不阻塞。
2. **正则天然精确**：`for (...)` 里 `[^;]*` 到 `:` 才匹配，传统 for 循环（含 `;`）不命中。
3. **同名容器匹配**：只报「遍历的容器被变更」，操作其他容器不误报。

## 验证（7 场景全过）

| 场景 | 结果 |
|---|---|
| 遍历中 Remove | ✅ 报 warning |
| 遍历中 Add | ✅ 报 warning |
| 遍历中只读 | ✅ 不报 |
| 操作其他容器 | ✅ 不报 |
| 传统 for 循环 | ✅ 不报（只匹配范围 for） |
| 逃生注释 | ✅ 不报 |
| 非 C++ 文件 | ✅ 跳过 |

## 收尾

ue_lint 规则集现为 R1-R16。生命周期资源检查完整闭环 8 条（R9-R16）。
