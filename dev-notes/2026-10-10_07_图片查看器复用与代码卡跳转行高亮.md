# 文件图片缩放拖拽 + 代码引用卡修分隔符/可点击跳转/行范围高亮

2026-10-10

## 起因（用户反馈三条）

1. 仓库文件预览里的图片（`type:'file'` 的 imgExts 分支）也要缩放拖拽（上次只给了外部会话图片 Tab）。
2. 代码引用卡还是"代码片段"折叠卡，代码不长也折叠——期望：全文展示，太长就滚动。
3. 卡头部文件名点不了；跳转文件后还要按行范围自动高亮定位。

## 关键弯路：fence 分隔符是 `:` 不是 `|`

上一轮 refMatch 正则按截图写成 `/^(\d+):(\d+)\|(.+)$/`（管道分隔）。实际数据里另一个会话
用的是冒号：```` ```792:848:IMMO_Client/Source/... ```` → refMatch 不命中 → 掉进
buildCodeFileCard(lang=整段info)，产出用户截图里的"代码片段"卡：徽标全大写、无高亮、
3 行折叠、文件名是猜的。**改成 `[|:]` 两种分隔符都收**（`12:34` 纯数字无路径不误伤）。

## 实现

`frontend/app.js`：

1. **文件图片查看器**：`_fillFilePane` imgExts 分支容器加 `height:100%;overflow:hidden;
   position:relative` + `es-image-viewer` class，渲染后调 `_esInitImageViewer`（完全复用，
   函数本来就是通用的，只是上次没接）。
2. **refMatch**：`[|:]` 双分隔符。
3. **文件名可点击**：`buildCodeRefCard` 头部 filename 加
   `onclick="openRepoFileFromChat(path, startLine, endLine)"`（单引号转义 `&#39;`，
   与 `_linkifyErrors` 做法一致）+ cursor/hover 样式。
4. **行范围跳转链路**：
   - `openRepoFileFromChat(filePath, lineStart, lineEnd)` 加可选参数，透传给
     `adsShell.openMain({type:'file', path, lineStart, lineEnd})`。
   - `openMain` file 分支：existing tab 上**无条件刷新** `lineStart/lineEnd`（带范围 → 锚点；
     不带 → 清掉，普通打开不受上次跳转影响）。openMain 每次激活都会 `_loadMainTabContent`，
     所以重复跳同一文件到不同行也会重渲染。
   - `_fillFilePane` 渲染完代码后调 `_applyFileLineAnchor(tabRef, body)`：给
     `[data-ln]` 在范围内的 `.main-ws-line` 加 `main-ws-line-hl`，首行 `scrollIntoView({block:'center'})`。
   - `_linkifyErrors` 的"文件:行号"链接走同一个 openRepoFileFromChat，自动获得单行高亮
     （lineEnd=lineStart）。旧仓库页 viewRepoFile 回退路径没做高亮（项目壳层是主路径）。

`frontend/styles.css`：

- `.main-ws-line.main-ws-line-hl`：淡紫底 + 左侧 2px primary 竖条 + 行号变色。
- `.chat-code-ref-file` cursor:pointer + hover 变色下划线。

## 验证边界

- `node --check` 过；refMatch 用 node 测了 5 组输入（`:` 分隔、`|` 分隔、普通 lang、空、
  纯行号无路径）均正确分流。
- 未跑浏览器实测。行范围超出文件实际行数时循环自然截断（dataset.ln 匹配不到就不加）。
- `scrollIntoView(block:'center')` 滚的是最近可滚祖先（.main-ws-pane-body），符合预期；
  但如果页面上方还有别的滚动容器可能连带微滚，未处理。
- 文件内容 < 起始行（比如跳 792 行但文件只有 100 行）→ 无高亮无滚动，静默。
