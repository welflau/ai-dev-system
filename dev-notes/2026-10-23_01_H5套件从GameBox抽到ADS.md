# H5 套件从 GameBox 抽到 ADS

2026-10-23

方案边界：`docs/20261019_01_Action成套插件与公共工具边界方案.md`
对照项目：`D:\A_Works\gamebox-ai`

## 起因

GameBox 是对话里直接出可玩 H5 的产品（Coordinator + Worker + Vite 沙箱）。ADS 是工单 SOP。评估结论：Phaser 领域能力可以按 UE 套件同一套边界进 `backend/plugins/`，编排引擎和预览进程不能搬。

## 实现

**套件** `backend/plugins/h5/`，trait 仍是唯一开关：`framework:phaser`（词表补了这一项）。

| 抽了什么 | 放哪 | 不抽什么 |
|---|---|---|
| 开发规范（结构 / 402×874 / 触控 / API 坑） | `skills/phaser-dev/SKILL.md`，SkillLoader 按 `inject_to` 注入 | Coordinator / Worker / SSE Studio |
| Vite + Phaser 脚手架 | `templates/phaser-vite/` + `instantiate_h5_template` | 整份 remarkablegames 模板、husky、二进制 |
| `tsc --noEmit` + Phaser 误用提示 | `h5_typecheck` + fragment `h5_typecheck.yaml` | Vite 进程管家、iframe 运行时错误 |

**流水线**：fragment 插在 `development` 之后，`reject_goto: development`。skill 的 `stage_id` 与 fragment 同名，组装器跳过插入（和 UE 编译同一过渡）。空 Phaser 仓库在 `DevAgent.develop` 里先落脚手架。

**识别**：`package.json` 依赖 `phaser` 会检出 `framework:phaser`。网页游戏再标这个 trait 才启用套件。`html_prototype` 对 Phaser 项目 `none_of`。

## 效果

「套件与插件 → ADS 套件」会多出 **H5 / Phaser**（2 Action + 2 skill）。打开带 `framework:phaser` 的项目会标「当前项目会启用」。

相关测试：`tests/plugins/test_h5_plugin.py`、目录/注册表/词表防漂。
