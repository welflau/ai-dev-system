## 本轮发现并修复的一个真实 bug

`actions/base.py:38-49` 的 `ActionResult.to_dict()` 会把 `data` **展开到顶层**：
```python
result = {**self.data}
if "status" not in result: result["status"] = "success" if self.success else "error"
```
初版把 VC 状态快照放在 `data["status"]`，会**覆盖**结果自身的 `status`，
成功结果被 Orchestrator 误读成 `in_progress` 阶段态。测试
`test_success_minimal_closed_loop` 当场抓到，已改名 `data["vc_status"]`。
**后续写 Action 都要注意：`status` 是保留字段，不能塞进 `data`。**
