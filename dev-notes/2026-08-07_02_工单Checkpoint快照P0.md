## 一、做了什么（P0）

对标 Cursor Checkpoint：**写盘前拍受影响文件内容**，取消工单优先按快照还原；无快照再走 Git 兜底。

### 1. 存储

- 表 `checkpoints` / `checkpoint_files`（`database.py` SCHEMA）
- Blob：`backend/data/checkpoints/blobs/{hh}/{sha256}`（`DATA_DIR`）
- 单文件上限 2MiB；二进制扩展名跳过

### 2. 服务

```
backend/checkpoint/
  context.py   # contextvars：project/ticket 写上下文
  store.py     # content-addressed blob
  service.py   # ensure_ticket_start / capture_before_write / restore_*
```

### 3. 写入钩子

| 漏斗 | 行为 |
|---|---|
| `orchestrator.process_ticket` | claim 后 `ticket_start` + `set_checkpoint_context`；finally 清理 |
| `git_manager.write_file(s)` | 有上下文则写前 `capture_from_active_context` |
| `WriteFileAction` | OpenSpec/Apply 写前按仓库相对路径 capture |
| `ArchitectAgent._run_openspec_propose` | 设置写上下文 |

### 4. API / 取消

- `GET .../checkpoints`、`GET .../checkpoints/{id}`
- `POST .../checkpoints/{id}/restore`（`confirm=true`）
- `GET .../revert-preview` → `strategy: checkpoint|git|none`
- `DELETE ...?revert=true` → 有 before_write 记录则 Checkpoint 还原，否则 Git

### 5. 前端

- 取消确认框展示策略（Checkpoint / Git）
- 时间轴识别 `checkpoint` / `checkpoint_restore` / `revert`
- 缓存：`app.js?v=20260807b`
