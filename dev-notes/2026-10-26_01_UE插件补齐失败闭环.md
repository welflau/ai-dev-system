# UE 插件按 H5 准入补齐失败闭环

2026-10-26

方案：`docs/20261024_01_UE插件对照H5准入约束的缺口与修改方案.md`  
标尺：`docs/20261023_01_插件套件准入规范与五道约束.md`  
同批入库的 H5 / 时间轴笔记：`2026-10-23_06` 到 `2026-10-23_10`，以及 `2026-10-24_01`。

## 起因

UE 套件能编译、试玩、打包，但失败闭环还在宿主里。`engine_compile_failed`、`play_test_failed`、`self_test_failed` 的反思写在 `agents/dev.py` 和 `actions/reflection.py` 的分支上。UBT、Automation、RunUAT 直接 `Popen`，时间轴没有后台任务。Playtest 超时一律打回开发。`git clean -fd` 会删掉 `Binaries`、`Intermediate`。`packaged` 在看板上落进「进行中」。

## 实现

插件自己接这三块，宿主只留分发：

- `backend/plugins/ue5/reflection.py` 接管六个打回状态：`engine_compile_failed`、`play_test_failed`、`self_test_failed`、`ue_test_gen_failed`、`packaging_failed`、`ue_content_failed`。日志不像 UBT（例如 Godot / Unity 的输出）时只给通用「引擎编译失败」，不塞 UE 宏提示。编译日志为空时写入 `context["_reflection_override"]`，跳过盲猜。`.h` 上能确定的两处直接改：类声明后补 `GENERATED_BODY()`，有 `UCLASS` 且报错点名 generated 头时补 `#include "Stem.generated.h"`。带「文件截断显示」的内容不写回磁盘。
- `backend/plugins/ue5/command_trace.py` 给编译、试玩、打包、截图、测试生成打 `skill_step_*`，并用 `record_traced_command` 落命令。`command` 一律收成字符串。
- `backend/plugins/ue5/acceptance.py` 从工单日志收集编译通过、试玩通过、自测阻塞和已打包，附最多 3 段 `.h` / `.cpp`。验收规则写明不得因读不到截图判 0 分。
- Playtest 超时：模块没加载，或根本没有测试输出，记 `error`，不打回改业务代码。测试已经跑完但进程没退出，或已经有失败用例，才是 `playtest_failed`。
- `git clean -fd` 额外排除 `Binaries`、`Intermediate`、`Saved`、`DerivedDataCache`。
- `packaged` 进看板「评审」列。`packaging_pending` 和 `ue_content_pending` 进「进行中」。

`plugins.registry` 里按失败类型找 `reflection.py`、按 traits 找 `acceptance.py` 的钩子，和上面这批 H5 笔记是同一套入口。宿主不再为这些 UE 状态名写 `elif`。
