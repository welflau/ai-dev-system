# H5 试玩门禁（不对仓库另开沙箱）

2026-10-23

前作：`dev-notes/2026-10-23_01_H5套件从GameBox抽到ADS.md`

## 起因

tsc 拦不住场景切不过去、`create()` 空指针、资源 key 写错。GameBox 用独立 Vite 沙箱 + iframe 收错；ADS 项目已经是 git 仓库，不该再开 `{DATA_DIR}/projects/{id}`。

## 实现

`h5_playtest` 对着**当前仓库**：

1. 缺 `node_modules` 时 `npm install`
2. `vite build`（不常驻 Dev Server）
3. 用标准库 HTTP 服 `dist/`
4. Playwright 无头打开 402×874，收 `pageerror` / `console.error`，看有没有 canvas
5. 关掉服务

SOP：`h5_playtest.yaml` 插在 development 之后、tsc 之后（priority 86），`TestAgent.run_h5_playtest`，失败 `reject_goto: development`。skill 与 fragment 同名，组装器不插第二段。

未装 Playwright 时：build 过也算过，结果带 `runtime_skipped`。不要把所有 H5 工单卡在缺浏览器上。

## 没做

独立沙箱目录、共享 node_modules、常驻 Vite、Studio iframe 预览面板。那些是产品形态，不是门禁。

相关测试：`tests/plugins/test_h5_plugin.py`。
