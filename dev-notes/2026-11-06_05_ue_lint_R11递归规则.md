# DevLog：ue_lint R11 递归规则

> 日期：2026-11-06
> 关联：`docs/20261105_07_QA日志闭环设计方案.md` 4.3.1（Phase 3b 替代路线）
> 位置：`plugins/ue5/actions/ue_lint/rules.py`

## 目标

延续 R9/R10 的交互检查扩展，落地第三条：R11 递归规则。

## 重构：提取共享 helper

R10 与 R11 都需要「收集 AddDynamic / BindAction 绑定的交互回调名」，提取 `_collect_interaction_callbacks(content, rule_id)` 供两者复用，消除重复。

## 设计

R11 检查交互回调体内是否递归调用自身（无限递归风险）。

**关键决策**：
1. **warning 级别**：同 R9/R10，保守不阻塞。
2. **`_find_func_body` 返回的 body 从 `{` 开始，不含函数签名**，所以 body 里的 `cb(` 都是调用（含递归）——直接正则搜 `\bcb\s*\(` 即可，无需排除定义行。
3. 兼容 `this->Func()` 与 `Func()` 两种调用形式（`\b` 词边界能匹配 `->` 后的函数名）。

## 实现

`rule_R11_recursive_callback`：收集回调 → `_find_func_body` 找函数体 → 正则搜同名调用 → warning。

## 验证（5 场景 + 1 回归全过）

| 场景 | 结果 |
|---|---|
| 回调体内递归调用自身 | ✅ 报 warning |
| 回调体内调用其他函数 | ✅ 不报 |
| `this->` 形式递归 | ✅ 报 warning |
| 逃生注释 | ✅ 不报 |
| 无交互绑定 | ✅ 不报 |
| R10 回归（重构后） | ✅ 仍正常报 warning |

## 收尾

交互检查三条规则（R9 委托配对 / R10 空引用 / R11 递归）全部落地，Phase 3b 替代路线完成。三条规则同为 warning 级别 + 确定性正则 + 逃生注释，可安全上线。
