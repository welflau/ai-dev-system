## 最重要的定性：这不是 MiniMax 官方 API

ComicAI 实读结论（`backend/app/api/v1/endpoints/video_mnmx.py` +
`Docs/鼠鼠工具-视频生成API文档.md`）：

- Base `https://www.runlive.top/mnmx`，鉴权 `X-Card-Key: sk_...`，**白名单放行制**
  （`video_mnmx.py:89`、`文档:11-14`）
- 无 `Authorization: Bearer`、无 GroupID、无 `file_id` retrieval、无 `T2V-01`/`MiniMax-Hailuo-*`
  （全 ComicAI 零匹配）
- 任务名 `minimax_h3_v2`（文生/首帧/首尾帧）、`minimax_h3_multi_ref`（多参考）
- 异步：提交 `POST /api/v1/tasks`（multipart）→ 轮询 `GET /api/v1/tasks/{id}`
  → 完成取 `GET /api/v1/tasks/{id}/file-url` 签名直链
- 限速：查询/下载 1 次/秒；凌晨 0-8 点 5 并发；`429/502/503/504` 退避
- 状态 `queued|processing|completed|failed`；错误在 `detail/message/error`
- 已知坑：`Docs/DevLog/2026-11-05_10:45` 记录签名直链可能是内网 IP
  （`http://172.22.5.8:8177/...`），从别的机器未必可达

**用户手上的官方 MiniMax API key 不能填进这套配置** —— 已在 `config.py` 注释与
`.env.example` 明确标注。将来接官方 `/v1/video_generation` 要另登记 provider。

## 架构决策：公共层，不属于 Plugin

依据 `docs/20261019_01_Action成套插件与公共工具边界方案.md:89`
「任何项目的工单循环或聊天都要用的留在公共模块」。ADS 现状也支持：
`backend/image_processor.py` 是公共生图 client，被 6+ 上层模块复用；
`plugins/director/lightai_video.py` 反向依赖它（依赖方向 `plugin → 公共层`）。

新建 `backend/cloud_video/`（与 `plugins/` 平级的领域包），单向 DAG：

```
plugins/* ──▶ backend/cloud_video/ ──▶ backend/config.py + 标准库
                    ✗ 不 import plugins / actions / database / events / git_manager
```

公共层**只做 transport + 协议编排**，抛分层异常：
- `CloudVideoUnavailable`（未启用 / 缺 key / 网络 / 超时 / 403）→ 调用方转 `env_missing → blocked`
- `CloudVideoError`（上游失败 / 参数错 / 协议异常）→ 调用方普通失败

**不返回 `ActionResult`、不写时间轴、不判 `env_missing`** —— 准入规范约束 2/3
（`docs/20261023_01_...:90-109`）规定这些是 Action/Plugin 层职责。§14.5 给了
Plugin 适配调用范例（本轮只给范例，未改任何 plugin）。

## 实现要点

- urllib 无原生 multipart → `_encode_multipart()` 手搓 boundary，文件以原始字节拼入。
- 参数归一化按鼠鼠文档 `:33-83`：`resolution` 三档（multi_ref 强制降到 `1`）、
  `duration` clamp 4–15 且首尾帧+1080P 最长 10s、`aspect_ratio` 必须整串、
  非法值回退默认，避免上游 400 拒单。
- 提交只对 `429/502/503/504` 退避重试（默认 3 次、间隔 5s）；402 积分不足等立即抛。
- `generate_video()` 一站式：submit → poll（`MINIMAX_H3_POLL_INTERVAL` 默认 5s，
  遵守查询 1 次/秒限速）→ `file_url` → 可选 `download`；轮询耗尽抛错但**保留 task_id**
  供调用方后续自行 `query`/`file_url`。
- `ping()` 沿用 ComicAI 的技巧：用不存在的 task id 反查，403=卡无效，404=鉴权通过
  （`video_mnmx.py:197-214`）。
- `PROVIDERS` 是 ADS 里最接近 `external_sessions/__init__.py:17-21` 的公共 registry 形态，
  后续加官方 MiniMax / Ark / LibTV 只需登记，配置仍走系统配置。

### 测试中修的一个小问题

初版 mock 用 `async def _call(**kw)`，而 client 内部传了位置参数 → TypeError。
把 client 的 4 处 `_call(...)` 调用统一改成全关键字参数（`method=`/`path=`），
既修了测试也让调用更清晰。另修了 bytes 字面量里放中文导致的 SyntaxError
（改成 `'...'.encode('utf-8')`）。
