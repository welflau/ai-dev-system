## 本阶段目标

建立「AI 生图 → 手动/对话触发 → UE Content 导入」的完整核心链路：
- 新增 `ue_import_asset` MCP Tool（AI 助手对话可直接调用）
- 工单路由支持资产导入类型
- 数据库记录导入后的 UE 内部路径

---

## 改动文件

### 1. `backend/database.py`

**改动**：migrations 列表追加一条

```python
("art_assets", "ue_path", "TEXT NOT NULL DEFAULT ''"),
```

**语义**：记录资产导入 UE 后的内部路径，如 `/Game/Textures/AI/T_IMG_abc12345`。空串 = 未导入。

---

### 2. `backend/ue_mcp_server.py`

**新增函数**：

- `_ue_import_asset_impl(asset_id, project_id, ue_dest_path, asset_name, timeout)` — 核心逻辑，供 MCP tool 和 `ue_editor.py` 共用
- `ue_import_asset(...)` — `@mcp.tool()` 装饰的对外工具

**执行链路**：

```
查 art_assets 拿本地路径
  → 验证文件存在
  → 构造 unreal.AssetImportTask Python 代码
  → _ue_run() → ue_python_bridge.run_python()
  → 检查 stdout 中 IMPORT_OK=True
  → 回写 art_assets.ue_path
```

**降级策略**：
- `art_assets.file_path` 为空时，从 `image_requests.result_path` 拿绝对路径
- Editor 未启动（`no_node` 错误）：返回明确提示，不挂起
- `ART_ASSETS_LOCAL_PATH` 未配置时：无本地文件，明确报错

**使用示例**（AI 助手对话）：
> 把资产 IMG-abc12345 导入当前 UE 项目的 /Game/Textures/UI

---

### 3. `backend/api/art_assets.py`

**新增端点**：

| 端点 | 用途 |
|------|------|
| `GET /api/art-assets/ue-imported?ue_path_prefix=/Game/` | 查询已导入 UE 的资产列表 |
| `PATCH /api/art-assets/{asset_id}/ue-path` | 手动修正 ue_path（body: `{"ue_path": "/Game/..."}` 或 `""` 清除） |

---

### 4. `backend/agents/ue_editor.py`

**改动**：

1. `execute()` 新增 `ue_import_asset` task_name 分支
2. `_do_auto_dispatch()` 新增关键词路由（`import`/`导入`/`texture`/`纹理`/`生图导入`）
3. 新增 `_do_import_asset(context)` 方法：
   - 从 context 或描述文本中解析 `IMG-xxxxxxxx` ID（正则）
   - 批量调 `_ue_import_asset_impl`，汇总成功/失败结果

---

## 调用路径总览

```
AI 助手对话（codebuddy CLI）
  → MCP tool: ue_import_asset
  → _ue_import_asset_impl
  → ue_python_bridge → UE Editor
  → 回写 art_assets.ue_path

工单处理（UEEditorAgent）
  → execute("ue_import_asset", context)
  → _do_import_asset
  → _ue_import_asset_impl（批量）
  → ue_python_bridge → UE Editor
```

---

## 前提条件（运行时）

1. UE Editor 已启动
2. Project Settings → Plugins → Python → **Enable Remote Execution Server** 已勾选
3. `ART_ASSETS_LOCAL_PATH` 已配置（否则无本地文件可导入）
