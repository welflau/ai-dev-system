# DevLog：ue_lint R13 弱引用检查规则

> 日期：2026-11-06
> 关联：R9-R12 生命周期资源检查
> 位置：`plugins/ue5/actions/ue_lint/rules.py`

## 目标

延续生命周期资源检查，落地 R13：弱引用解引用守卫（TWeakObjectPtr）。

## 设计动机

TWeakObjectPtr 是 UE 的弱对象指针，**不阻止 GC**——对象可能已被回收。直接 `WeakVar->` 解引用会崩溃（operator-> 内部 Get() 后直接解引用，失效即空指针崩溃）。

这是 UE 常见且危险的 bug，与 R10（空引用）相关但更聚焦：R10 管"非 this 指针访问"，R13 管"弱引用解引用"。

## 设计

- `_RE_WEAK_DECL`：收集 `TWeakObjectPtr<Type> VarName` 声明的变量名
- 对每个弱引用变量，找 `VarName->` 解引用
- 检查解引用点前 200 字符内是否有守卫：`IsValid(var)` / `var.IsValid()` / `var.Get()`
- 无守卫 → warning

**关键决策**：
1. **warning 级别**：对象可能确实存活（如刚赋值），保守不阻塞。
2. **三种守卫模式**：覆盖 UE 常见的判空写法。

## 验证（6 场景全过）

| 场景 | 结果 |
|---|---|
| 弱引用解引用无守卫 | ✅ 报 warning，含变量名 |
| `var.IsValid()` 守卫 | ✅ 不报 |
| `IsValid(var.Get())` 守卫 | ✅ 不报 |
| `var.Get()` 判空 | ✅ 不报 |
| 无弱引用声明 | ✅ 不报 |
| 逃生注释 | ✅ 不报 |

## 收尾

ue_lint 规则集现为 R1-R13。生命周期资源检查完整闭环：委托配对(R9)/空引用(R10)/递归(R11)/Timer配对(R12)/弱引用守卫(R13)。
