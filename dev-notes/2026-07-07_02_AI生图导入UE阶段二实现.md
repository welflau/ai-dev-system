## 本阶段目标

图片生成完成后，**无需人工干预**，系统自动检测 UE Editor 是否在线，若是则直接触发导入，并通过 SSE 推送通知到前端。

---

## 改动文件

### 1. `backend/image_processor.py`

**新增函数**：`_maybe_import_to_ue(req_id, req, result_path)`

**执行逻辑**：

```
process_image_request 完成
  → result_path 有效 + project_id 存在
  → asyncio.create_task(_maybe_import_to_ue)  ← 非阻塞后台任务
      → 查 projects.uproject_path，确认是 UE 项目
      → ue_python_bridge.run_python("print('online')", timeout=5s) 探活
      → Editor 离线 → debug log，静默退出
      → Editor 在线 → _ue_import_asset_impl(req_id, project_id, "/Game/Textures/AI")
      → 推 SSE event_manager.publish_to_project("ue_asset_imported", {...})
      → 任何异常 → debug log，不影响主流程
```

**关键设计点**：
- 用 `asyncio.create_task` 非阻塞，不影响生图主流程的响应速度
- 探活超时 5 秒，导入超时默认 60 秒（`_ue_import_asset_impl` 默认值）
- 全程 try/except，失败静默忽略
- 只有非 UE 项目（无 `uproject_path`）才跳过，普通项目零影响

### 2. `frontend/app.js`

**新增 SSE 监听**：`ue_asset_imported`

- 成功：`showToast("🎮 已自动导入 UE：/Game/Textures/AI/T_xxx", 'success')` + 操作日志
- 失败：操作日志写 warn 级别（不弹 toast，避免打扰用户）

## 完整阶段二流程图

```
用户发起生图（/api/image-gen 或 GENERATE_IMAGE action）
        ↓
LightAI 异步任务轮询完成
        ↓
图片下载到 ART_ASSETS_LOCAL_PATH/2d/generated/
        ↓
SSE: image_generated（前端刷新图片队列）
        ↓
asyncio.create_task（后台，不阻塞）
        ↓
     ┌─────────────────────────────────────┐
     │  _maybe_import_to_ue                │
     │  1. 查 projects.uproject_path       │
     │  2. ue_python_bridge 探活 (5s)      │
     │  3. _ue_import_asset_impl (60s)     │
     │  4. SSE: ue_asset_imported          │
     └─────────────────────────────────────┘
        ↓
前端 toast: 🎮 已自动导入 UE + 操作日志
```

---

## 注意事项

- **ART_ASSETS_LOCAL_PATH 未配置**：`result_path` 为空，`_maybe_import_to_ue` 不会被调用（调用条件 `result_path and req.get("project_id")`）
- **非 UE 项目**：`uproject_path` 为空时提前 return，零副作用
- **Editor 未启动**：探活失败静默跳过，下次生图再试
- **重复导入**：`_ue_import_asset_impl` 设 `replace_existing=True`，覆盖已有资产，不会报错
