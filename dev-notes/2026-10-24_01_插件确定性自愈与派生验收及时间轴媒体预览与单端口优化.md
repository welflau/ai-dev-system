# H5 插件确定性自愈 + 派生产品验收 + 时间轴媒体/试玩预览 + 8000 单端口托管与面板防卡死

2026-10-24

前作：`dev-notes/2026-10-23_10_H5失败信号接入Reflection与自动诊断.md`

## 起因

在真实跑通 `PhaserGame`（`PRJ-20261023-6d823e`）全部 6 张工单的端到端流水线过程中，暴露出以下核心问题：

1. **为什么 `fix_issues` 拿不到插件失败信号、且单次改代码耗时 10+ 分钟？**
   - **状态覆盖 Bug**：`orchestrator.py:1820` 在派单给 `DevAgent.fix_issues` 之前，先把数据库里的 `tickets.status` 更新成了 `development_in_progress`；随后 `DevAgent._do_fix_issues` 去查 `SELECT status FROM tickets` 时永远读到 `development_in_progress`，导致从来没进过 `h5_typecheck_failed` 分支，每次都落回默认兜底 `testing_failed`（提示 `无具体 issue`）。
   - **CLI 空转与全量重规划**：`codebuddy` CLI 在项目仓库 `cwd` 下修改单文件时会自主跑 `git status/log`、读无关文件，且 `PlanCodeChange` 把 6～7 个无关文件（含 400+ 行的 `*.spec.ts`）列进重改清单。
   - **大文件截断标记写回磁盘**：`memory.py` 对 `>15,000` 字符的文件加了 `/* ... [文件截断显示] ... */`，修复时若优先取内存 `existing_code` 而非磁盘原文件，会把截断后的残缺代码写回硬盘。
2. **为什么 `ProductAgent.acceptance_review` 报「无法完成验收（0/10）」？**
   - CLI 纯文本生成运行在隔离目录（无工具），公共 `AcceptanceReviewAction` 只传了截图相对路径和文件名列表，既没有传 `h5_playtest` 的客观运行报告，也没有传核心源码，导致模型因读不到 `.png` 文件而判 0 分拒绝验收。
3. **后台任务面板「实时思考流」为何只显示 3 行、之后又涨到 13,991 行卡死？**
   - 最初复用了底部 100px 迷你日志条的 DOM 文本（被 `slice(-280)` 截断成 3 行）；
   - 改为独立累加缓冲后，分割头用了 `.split('── 实时思考流 ──')` 而拼接头写了 `'── 实时思考流（持续累加） ──'`，导致每次收到 token 都把旧 `rt.output` 翻倍拼接，几百个 token 后暴涨到 14,000+ 行卡死页面。
4. **时间轴缺少资产图/测试截图缩略图与在线试玩入口，且 `DeployAgent` 开了 25 个随机端口触发 Cursor 弹窗**：
   - 历史工单流转到 `deployed` 后 `tickets.result` 被覆盖，自测截图、H5 试玩截图、验收截图、占位资产图及在线试玩链接未在时间轴呈现；
   - `DeployAgent.deploy_env` 使用 `hash(project_id)` 计算端口，每次 Python 进程重启随机盐值变化都会新开一个 `python -m http.server 9xxx` 端口（累计残留 25 个子进程），且触发 Cursor IDE 自动弹出内置浏览器 Tab。
5. **看板缺水平滚动条 & 隐藏右侧面板后再点右上角按钮消失并卡死**：
   - `#tab-board` 外层 `.tab-content.active` 写了 `overflow-x: hidden`；
   - `.project-layout` 中间列 `1fr` 缺 `min-width: 0`，被后台任务长行撑到 `2000px+`，把第 3 列 `#rightWorkbench` 和 `#rwToggleBtn` 挤出屏幕右边界；同时 `openRight()` 同步渲染 6 张工单共 1,523 条（2.87MB）历史对话阻塞主线程。

## 实现

### 1. 插件级确定性自愈（`apply_deterministic_fixes`）与编译错误直达快通道
- **透传 `trigger_status`（`backend/orchestrator.py` + `backend/agents/dev.py`）**：Orchestrator 在更新状态前将 `context["trigger_status"] = current_status` 传入 Agent，兜底反查最近一条 `reject` 日志的 `to_status`。
- **H5 插件确定性快修器（`backend/plugins/h5/reflection.py` + `backend/plugins/registry.py`）**：
  - 实现 `apply_deterministic_fixes`，0 LLM Token 秒级自动修复 6 类高频 TS/Phaser 错误：
    1. `TS2345`：Phaser 颜色参数 `string -> number`（自动转 `0xRRGGBB` 或 `Number.parseInt`）；
    2. `TS2307`（本地幻觉模块如 `../scenes/PreloadScene`、`../scenes/UIScene`）：自动注释幻觉导入并从 `scene: [...]` 数组中移除；
    3. `TS2307`（无类型声明的第三方包如 `pngjs`）：自动注入 `// @ts-ignore`；
    4. `TS6133`：未使用变量/导入自动清理或补 `void varName;`；
    5. `TS2353`：Phaser `TextStyle` 的 `fontWeight` 自动替换为 `fontStyle`；
    6. `TS2532` / `TS2339`：`noUncheckedIndexedAccess` 数组/Buffer 下标自动补 `!`，`require('pngjs')` 解构修正。
  - 当报错文件已被插件 100% 确定性修复时，`DevAgent` 直接跳过 LLM 反思与重写。
- **编译错误直达快通道 & 磁盘原文件优先（`backend/actions/plan_code_change.py`）**：
  - 有精确 `compile_errors` 时只修改报错文件，跳过 `test/*.spec.ts` 重写，并向 Prompt 注入 `## 仓库真实存在的文件列表`；
  - 读取待改文件内容时**一律优先从仓库磁盘读取完整未截断文件**，杜绝将 `memory.py` 的 15,000 字截断标记写回硬盘。
- **CLI 纯生成隔离目录（`backend/llm_client.py`）**：非聊天类纯生成调用将 `cwd` 切至临时空目录 `ads_cli_pure_gen` 且不挂载 MCP，杜绝 CLI 自主跑 `git log/status` 空转。

### 2. 插件级产品验收派生能力（`backend/plugins/h5/acceptance.py`）
- 在 `backend/plugins/registry.py` 新增 `build_plugin_acceptance_evidence(context)` 钩子；
- 新建 `backend/plugins/h5/acceptance.py`，自动捞取本工单最近一次 `h5_typecheck` 与 `h5_playtest` 的客观检测结果（Canvas 挂载状态、尺寸、运行时 0 报错、对比度检查）及核心源码片段，派生注入 `AcceptanceReviewAction`，明确禁止因纯文本环境不直接读 `.png` 文件而判 0 分；
- 同步更新 `docs/20261023_01_插件套件准入规范与五道约束.md`（新增约束 6 及 Checklist）。

### 3. 时间轴关键截图/资产缩略图预览 + 在线试玩按钮 + 8000 端口内置托管
- **全阶段媒体与试玩链接回填（`backend/api/tickets.py::_annotate_media_previews`）**：
  - 自动从 `artifacts(type='asset_manifest')` 提取占位资产图（`*.png`），从 `docs/Reqs/<req>/<ticket>/screenshots/` 扫描回填开发自测截图（`dev_*.png`）、H5 试玩截图（`h5_playtest.png`）、产品验收截图（`acceptance_*.png`）以及报告芯片（`📋 dev-notes.md` / `📋 code-review.md` / `📋 acceptance-review.md`）；
  - `/api/projects/{id}/git/file-raw` 支持跨分支 `git show <branch>:<path>` 读取图片字节流；
  - 前端渲染 `.tl-media-grid` 缩略图卡片、自测 7 项检查徽章（`.tl-check-pills`）与 **`🎮 在线试玩预览`** 按钮，点击直接在左侧主工作区新建图片 Tab 或内置 Web 试玩 Tab。
- **零额外端口内置预览路由（`backend/api/projects.py` + `backend/agents/deploy.py`）**：
  - 新增 `/api/projects/{project_id}/preview/{env_type}/{asset_path:path}`，直接用 ADS 8000 主端口托管 `dist/` 构建产物（并在每次部署时强制同步最新 `dist/` 到 `_test` / `_prod` 目录）；
  - 彻底废弃 `python -m http.server 9xxx` 子进程，清理全部 25 个残留端口进程，根治端口漂移与 Cursor 自动弹窗。

### 4. 后台任务累加流防翻倍、看板水平滚动条与右侧面板防卡死
- **修复思考流翻倍拼接（`frontend/app.js`）**：缓存 `rt._baseHeader` 并以 `/\n*── 实时思考流/` 分割，加 `120ms` 渲染节流，支持持续累加且不卡主线程。
- **看板底部常驻水平滚动条（`frontend/styles.css`）**：`#tab-board` 改为纵向 Flex 布局，`.board` 独立承载横向滚动并加宽滚动条（`height: 10px`）。
- **右侧面板秒开防挤压（`frontend/styles.css` + `frontend/app.js` + `backend/api/chat.py`）**：
  - `.project-layout` 中间列改为 `minmax(0, 1fr)`，子容器补齐 `min-width: 0; overflow: hidden;`，防止后台任务长行把右侧面板和右上角开关挤出屏幕；
  - `/chat/tickets/conversations` 聚合接口限制每单返回最近 50 条（响应从 `2.87MB` 降至 `374KB`），前端长气泡初始只渲染 600 字预览、展开时按需渲染全文，`openRight()` 推迟到下一帧加载历史，实现 0 延迟丝滑切换。
