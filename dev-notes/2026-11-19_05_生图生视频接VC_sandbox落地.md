## 背景

用户指示「生图 生视频 用先接上现有接口」——即不走 VC 的 6 阶段项目流程
（`vc_run_project`），而是把 VC **已经现成提供的**单次生图 / 生视频接口直接接成 ADS 的 Action。

## 选型：sandbox 同步，不用 pipelines

VC 有两套「单次」能力。`api/routers/sandbox.py` 是 5 个同步 POST（一次调用直接返回产物），
`api/routers/pipelines.py` 是异步多阶段短片流水线（LLM 分镜 → 多图 → TTS → 多段视频 → ffmpeg 拼接，
还要额外 LLM key / edge-tts / ffmpeg / 可能 Playwright）。做「单次生图/生视频」用 pipelines 属于
杀鸡用牛刀，故只接 sandbox 的 `t2i` / `i2i` / `video` 三个端点。

### 两个必须兜底的坑

1. **HTTP 200 也可能是失败**：客户端加 `_require_success()` 查 `success` 字段，
   不能只看状态码。否则 VC 报 `ARK_API_KEY not set` 会被当成功处理。
2. **Windows 路径 bug**：VC `_normalize_path`（`sandbox.py:56-73`）用
   `path.startswith('/')` 判绝对路径，是 POSIX 假设。本机 Windows 下复算确认返回：
   ```
   result/G:\Github\...\backend\code\result\sandbox\videos\a1b2.mp4
   ```
   直接拼 `/code/` 必然 404。ADS 侧 `normalize_media_rel()` 统一兜底：
   反斜杠转正 → 取最后一个 `code/` 之后 → 补成 `result/...`。
   pipelines 返回的绝对路径也能一并处理。**未改 VC 源码**（沿用零改造结论）。

### 设计要点

- **`vc_gen_video` 缺 `image` 时自动先 `t2i` 出首帧**：因为 VC 没有纯文生视频。
  自动首帧的路径归一化后拼回 VC 自己可访问的 `/code/` URL 传给 `video.image`。
  **这是两次付费调用**，已在 Action description 与返回 `auto_first_frame` 字段明确标注。
- **模型动态取**：从 `GET /api/config` 的 `models.image_t2i` / `image_it2i` / `video` 读，不写死。
- **产物落盘**：`works/<slug>/videoclaw/{image,video}/`；文件名白名单 `^[A-Za-z0-9_.-]+$`，
  非法名回退 `vc_media.png` / `vc_media.mp4`；slug 同样白名单，防路径穿越。
  未提供 `repo_path` 时只返回 VC URL（`downloaded=False`），不写盘。
- **长超时**：`VIDEOCLAW_VIDEO_TIMEOUT=900` 单独用于 `sandbox_video`；
  `VIDEOCLAW_TIMEOUT=600` 在 Kling 边界情况会先超时而 VC 后台仍在生成。
- **准入约束**：`vc_` 前缀（不撞 `gen_image` / `gen_video`）、`env_missing → blocked`、
  `command` 为 `str`、`task_id` 落 `TCMD-*`、不建 `reflection.py` / `acceptance.py`。

## 必须人完成（动态，未做）

1. 填 VC `config.yaml` 的 `dashscope` / `ark` api_key
2. `cd VC/backend && uv sync`，确认 ffmpeg / Playwright Chromium
3. `uv run python api_server.py` 起 sidecar，`curl :8100/api/health` 通
4. `backend/.env` 置 `VIDEOCLAW_ENABLED=true`，重启 ADS
5. 跑 `vc_gen_image`（cost：1 次图片调用）、`vc_gen_video`（不给 image 时是 2 次付费调用）
6. 确认产物非空、落在 `works/<slug>/videoclaw/{image,video}/`、时间轴有 `TCMD-*`
7. 停服后确认返回 `env_missing → blocked`；回归 `gen_image` / `gen_video` 不变
