# DevLog：ue_lint R17 同步加载规则

> 日期：2026-11-06
> 关联：R9-R16 生命周期资源检查
> 位置：`plugins/ue5/actions/ue_lint/rules.py`

## 目标

延续生命周期资源检查，落地 R17：TSoftObjectPtr 同步加载。

## 设计动机

`LoadSynchronous()` 会同步从磁盘加载资源，阻塞主线程造成卡顿。UE 官方明确建议运行时用 `FStreamableManager.RequestAsyncLoad` 异步加载 + 回调。这是明确的反模式，确定性正则即可检出。

## 设计

- `_RE_LOAD_SYNC`：匹配 `Var.LoadSynchronous()` 调用
- 提取软引用变量名，报 warning

**关键决策**：
1. **warning 级别**：启动阶段一次性加载是合理的（有逃生注释兜底）。
2. **实现极简**：单正则匹配，无上下文分析。

## 验证（5 场景全过）

| 场景 | 结果 |
|---|---|
| LoadSynchronous | ✅ 报 warning，含变量名 |
| 无 LoadSynchronous | ✅ 不报 |
| 逃生注释 | ✅ 不报 |
| 非 C++ 文件 | ✅ 跳过 |
| 多个 LoadSynchronous | ✅ 各报一条 |

## 收尾

ue_lint 规则集现为 R1-R17。生命周期资源检查完整闭环 9 条（R9-R17），覆盖：委托配对、空引用、递归、Timer 配对、弱引用、UPROPERTY、Cast 判空、遍历变更容器、同步加载。
