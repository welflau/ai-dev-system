# 纯图片消息被 min_length=1 拒绝修复

2026-10-12

## 现象

只发一张图片、不带文字时，聊天报
`请求失败: String should have at least 1 character`（前端兜底文案还多嘴一句
"请检查 LLM 是否已配置"，误导）。

## 根因

前端 `sendChat` 只发图片时 `fullMessage` 为空，后端 `ChatRequest.message` 写了
`Field(..., min_length=1)`，Pydantic 直接 422 拒绝。

## 修复（`backend/api/chat.py`）

- `ChatRequest` / `GroupChatRequest` 的 `message` 改为 `Field(default="")`，加
  `model_validator`：message 和 images **不能同时为空**（纯图片放行、全空拒绝）。
- `_build_user_content`：text 为空时不再追加空 text block（Anthropic 会拒），改为
  占位「（用户发送了图片，请查看并分析）」。

## 验证

Pydantic 校验：纯图片 ✓ / 纯文字 ✓ / 同时为空正确拒绝 ✓。重启后端生效。
