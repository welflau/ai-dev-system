# H5 失败信号接入 ReflectionAction + 看板动态状态兜底 + 工单全屏按钮

2026-10-23

前作：`dev-notes/2026-10-23_09_验收CLI超时与JSON二次提取切碎对象修复.md`

## 起因

1. **为什么 ADS 的 AI 分析不出修复方案？**
   - `DevAgent._do_fix_issues`（`backend/agents/dev.py`）识别了 `h5_typecheck_failed` 和 `h5_playtest_failed`，但只从 `reject` 日志里取了 `errors / warnings / command`，**没取 `raw_tail` 和 `hints`**；
   - 更致命的是：`ReflectionAction.run`（`backend/actions/reflection.py:203-319`）的 `if/elif` 分支里**根本没有 `h5_typecheck_failed` 和 `h5_playtest_failed` 分支**！
   - 于是走到了最后的 `else:`，喂给反思 LLM 的全部失败信号只有短短一行字：`失败类型: h5_typecheck_failed`（既没有 `tsc` 报错行，也没有 `raw_tail`，也没有 Phaser API 提示），AI 等于蒙着眼睛盲猜，自然分析不出正确的修复方案。
   - 此外，当工单因 `max_retries` 连续失败进入 `blocked` 时，`orchestrator.py` 的两处止损出口（`1609` 与 `1695`）没有调用 `_diagnose_blocked_ticket`，导致工单卡住后没有自动生成「🩺 AI 诊断」方案。
2. **切分支误删 `node_modules` 与 `npx --yes tsc` 假包陷阱**：
   - `git_manager.switch_branch` 跑 `git clean -fd` 时未排除 `node_modules`，切分支把依赖删空；
   - `h5_typecheck` 未自动 `npm install`，回退调 `npx --yes tsc` 命中了 npm 上的废弃占位包 `tsc`（打印 `This is not the tsc command you are looking for` 并 `exit 1`，0 个 TS 错误）。
3. **看板动态状态消失 & 工单详情缺全屏按钮**：
   - `/api/projects/{project_id}/board` 只按静态 `BOARD_COLUMNS` 过滤，`h5_playtest_passed` 等动态状态不在任何一列；
   - 工单抽屉右上角缺少与对话面板同款的全屏按钮。

## 实现

1. **`ReflectionAction` + `DevAgent._do_fix_issues` 完整打通 H5 失败信号**：
   - `dev.py` 从最近一条 `reject` 日志中完整提取 `compile_errors`、`compile_warnings`、`compile_command`、`compile_hints`、`compile_raw_tail`、`compile_err_brief`；
   - `reflection.py` 新增 `elif failure_type in ("h5_typecheck_failed", "h5_playtest_failed"):` 分支，将具体文件行列报错、Phaser API 修复提示（`hints`）以及剥离 ANSI 后的 `raw_tail` 一并注入反思 Prompt。
2. **重试超限进入 `blocked` 时自动触发 AI 诊断**：
   - `orchestrator.py` 在 `global_reject_limit` 与阶段 `max_retries_exceeded` 两处 `blocked` 分支均启动 `asyncio.create_task(self._diagnose_blocked_ticket(...))`。
3. **`h5_typecheck` 自动装依赖 + `--package typescript` + `git clean` 保 `node_modules`**：
   - `git_manager.switch_branch` 的 `git clean -fd` 增加 `--exclude=node_modules`；
   - `h5_typecheck` 缺 `node_modules/.bin/tsc` 时先自动跑 `npm install`（写时间轴与任务 Log），`npx` 兜底改为 `npx --yes --package typescript tsc --noEmit`。
4. **看板动态状态兜底 (`_classify_board_column`) & 工单全屏按钮 (`toggleTicketFullscreen`)**。

相关测试：`tests/plugins/test_h5_plugin.py`（26 项全绿）。
